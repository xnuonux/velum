# velum ... living websites

bring a name and a few true sentences. leave with a complete, breathing site ... a shader ground that drifts, a cursor that feels like touching water, glass floating on the deep, reveals on the planetarium curve ... in ONE self-contained html file you own outright.

the anti-template-builder. it cannot make an ugly one, because the quality floor is held by construction, not by hope.

## what is built (v0.2, honest)

- **the forge** ... name + story + shape (portfolio / landing / personal / studio / product) + a stone. the stone can be chosen by your own words (deterministic material-word inference ... a taste engine over curated stones, not a model, and it says so).
- **six stones** ... the veil, oxblood, emerald, cobalt, gilded, marble (the one light dialect). each is a material: a five-stop shader ramp, ink, metal, glass, hairline.
- **the drafter** ... a seeded, deterministic first draft of every section from your own sentences + curated banks. placeholders say they are placeholders. redraft cycles the seed.
- **the bench** ... live editing of every section (headings, bodies, works, features, tiers, quote, contact, long-form prose), stone swapping, the five living cursors (moon / water / ember / gem / dither ... dither makes the ground itself follow the hand), drift + dim tuning. the preview iframe renders the exact export, byte for byte.
- **the sections are yours** ... add a section of any kind (hero / statement / work / gallery / prose / features / tiers / quote / contact), move them up and down, remove them. works pieces take real image uploads, embedded as data urls in the export.
- **galleries as a first-class section kind** ... a multi-image grid of quiet frames with captions (4/3, hairline, presence placeholders until you upload real images). drafted into portfolio and personal pours; frames add, remove, and embed like works images.
- **the quality floor as rows** ... contrast genuinely computed (7:1 floor on ink, 4.5:1 on the metal so eyebrows stay readable), no-flat-fill / alive / coherence / real-materials / motion-composed held by construction and labeled so. taste-judged dimensions stay with human eyes ... no machine grades its own beauty here.
- **the export** ... one html file: webgl veil shader (honest degradation ... no webgl leaves the deep gradient, reduced motion gets one still textured frame), the cursor, the reveals, all inlined. google fonts is the only external touch. no cdn scripts, no telemetry, no builder lock-in.
- **two pages, one file** ... every pour is a tiny site: a shared glass nav hash-routes two views (#/ the pour, #/deeper the second page ... the archive / the letters / the practice / the deeper telling, by shape), the footer spans both, and sections flip pages from the bench ... still one self-contained html, no server needed.
- **paid once, yours forever** ... $49 one-time per pour via stripe (payment link + a tiny netlify function that verifies the session and unlocks by `client_reference_id`). revisions to an unlocked pour are free forever. the three proof pours live in `public/showcase/`.
- **sovereign** ... sites persist in localStorage; nothing leaves the machine except the file you choose to download.
